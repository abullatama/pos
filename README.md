# Aplikasi Kasir Laundry dan Cafe

Paket awal untuk pengembangan dengan coding agent. Mulai dari `AGENTS.md`, lalu `progress.md` dan `feature_list.json`.

- `docs/spec/`: Spesifikasi Terpadu MVP v2.2, satu berkas per bagian
- `docs/`: aturan bisnis, arsitektur, keputusan, pertanyaan terbuka, UI, brief milestone
- `contracts/`: `openapi.yaml` (v0) dan `test-vectors.json`
- `seed/`: data contoh untuk pengembangan
- `tools/`: skrip verifikasi

AGENTS.md untuk backend dan web ditulis setelah stack dipilih (docs/decisions.md D-11).
